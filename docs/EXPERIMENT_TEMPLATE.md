# 实验记录模板

- 研究问题与可被否定的假设：
- 最近工作的区别（若无，写“工程复现/基线”）：
- 数据来源、许可、版本和下载日期：
- 输入文件 SHA-256 与排除规则：
- 测站/流域/来源身份及连通组件定义：
- 训练、验证、测试的角色和边界：
- 预测步长、历史窗口、间隔、特征实际可见时间：
- 缺失值、异常值、单位与预处理拟合范围：
- 基线、模型、完整参数、随机种子与代码提交：
- 主指标、聚合单位、未标注/缺失金标规则：
- CPU/GPU、线程、时间、费用和中止条件：
- 已经查看过哪些验证/测试结果：
- 运行命令与输出文件：
- 主结果、负结果、异常和修订原因：
- 独立验证范围与尚不能得出的结论：

冻结协议与哈希记录能帮助审计，但不能使已经看过的数据重新成为盲测数据。
